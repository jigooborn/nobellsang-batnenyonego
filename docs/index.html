100년의 기록을, 오늘의 눈으로

천문학의 표준 참고자료 SIMBAD의 분광형은 1890년대 사진건판 분류까지 거슬러 올라가는 소중한 축적 자료입니다. 본 연구의 AI는 이 라벨과 독립적으로 별을 재판정하고, 판정이 어긋난 별을 제3의 물리량(문헌 실측 온도)으로 심판해 갱신 검토가 필요한 별의 목록을 만들었습니다.

Mission

스펙트럼만으로 판정한다

외부 정보는 일절 사용하지 않습니다. 시선속도와 성간소광량까지 스펙트럼 스스로에게서 알아내고, 판정의 근거가 된 흡수선을 화면에 표시해 결정을 눈으로 검증할 수 있게 했습니다.

01

데이터

LAMOST · SDSS(MaStar/SEGUE) · MILES 4개 국제 서베이의 273,301개 스펙트럼. Gaia DR3 크로스매칭으로 같은 별을 그룹화한 정답지 222,381행.

02

전처리 9단계

진공→공기 파장 변환, 도플러 보정, 성간소광 보정, 연속선 정규화 — 물리 변수를 통제해 별의 본모습만 남깁니다.

03

두 개의 눈

스펙트럼 전체를 학습하는 CNN(ResNet)과 물리 지표 39개(빈의 변위 법칙 · 사하-볼츠만 · 압력 넓어짐)를 입력받는 MLP의 앙상블. 두 판정이 어긋나면 특이 천체 경고.

04

검증 4단계

홀드아웃 → 별 그룹 단위 5-fold 교차검증 → 24만 개 전수검사 → 학습에 쓰지 않은 별도 망원경(VLT) 데이터.
