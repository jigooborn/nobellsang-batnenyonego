무엇을 하는 프로그램인가

항성 스펙트럼 파일(FITS/CSV)을 열면 전처리부터 판정까지 자동으로 수행하여, 분광형(OB·A·F·G·K·M) · 광도계급(거성/주계열/백색왜성) · 유효온도 · 표면중력을 한 번에 예측합니다. 스펙트럼 외의 어떤 정보도 사용하지 않으며, 판정의 근거가 된 흡수선을 스펙트럼 위에 표시해 결과를 눈으로 확인할 수 있습니다.

AI가 물리를 배웠다는 증거

모델이 예측한 온도와 표면중력만으로 별들을 배치하자, 천문학의 상징인 H-R도의 구조 — 주계열과 적색거성가지 — 가 그대로 나타났습니다. 데이터를 암기한 것이 아니라 별의 물리를 스펙트럼에서 읽어냈다는 뜻입니다.

100년 된 라벨의 독립 검증

천문학의 표준 참고자료인 SIMBAD의 분광형은 1890년대 사진건판 분류까지 거슬러 올라가는 여러 시대의 판정이 축적된 자료입니다. 본 프로그램으로 469개 별을 독립 재판정하고 불일치 사례를 문헌 온도로 심판하여, 갱신 검토가 필요한 후보 75개를 선별했습니다.

대표 사례 — HD 338529
SIMBAD 등록: B5 → AI 판정: F형 (96%)
독립 문헌 실측 온도 6,165K = F형 구간 — 등록 라벨의 재검토를 시사

어떻게 만들었나

  • 데이터 — LAMOST · SDSS(MaStar/SEGUE) · MILES 4개 서베이 273,301개 스펙트럼, Gaia DR3 크로스매칭 정답지 222,381행
  • 전처리 9단계 — 진공→공기 변환, 도플러 보정, 성간소광 보정, 연속선 정규화 등
  • 모델 — 스펙트럼 전체를 학습하는 CNN(ResNet) + 물리 지표 39개를 입력받는 MLP 앙상블
  • 물리 기반 설계 — 빈의 변위 법칙(색지수), 사하-볼츠만 법칙(흡수선 등가폭), 압력 넓어짐(선폭→광도계급)
  • 검증 4단계 — 홀드아웃 → 5-fold → 24만 개 전수검사 → 외부 망원경(VLT) 데이터
